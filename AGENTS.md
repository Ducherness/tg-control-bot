Всегда читать и записывать текстовые файлы в UTF-8.
Не восстанавливать файлы через PowerShell-пайпы или команды, которые могут перекодировать вывод.
Для возврата файла из git использовать `git restore`/`git checkout-index`, а не `git show > file`.
Не менять encoding существующих файлов без явной необходимости.
